# money-manage 移动端 UX / 产品 P0（落地包）

> PM / UX / 移动排版 / 图表子 agent 未交付完整结论时，按协调默认 P0 执行。  
> 交互分轨见 `lib/ux-contract.ts`（PC=popover；移动=sheet；断点 ≤639px）。

## 目标 / 非目标

- **目标**：手机上能快速改参、看剩余%、管支出、跳到走势图并看懂三张图；支持**多用户账号**（注册 / 登录 / 登出）；**未登录可进主应用（访客 / 示例数据）**，注册后可认领当前草稿到云端。
- **非目标**：完整 CFP、复杂多账户权限、Auth SaaS、邮箱验证、找回密码、团队共享；不重启服务器（「重启网站」纯客户端）。

## 账号与数据边界

| 项 | 约定 |
| --- | --- |
| 进门 | **默认访客进主界面**（示例 / 本机草稿）；顶栏有「访客」chip +「注册保存」；可选全屏门禁已弱化，不再强制登录 |
| 访客写盘 | 只写 `localStorage`（`money-manage-profile`）；**不** PUT `/api/profile` |
| 注册认领 | 空账号 → **直接**把当前内存/localStorage 画像写入云端 |
| 登录空账号 | 云端为空时 **二次确认**是否绑定访客草稿；取消则不上传 |
| 登录有数据 | 用云端覆盖本地展示 |
| API | `/api/profile` 等仍须登录 |
| 隔离 | KV/本地键：`user:{id}` · `session:{token}` · `user:{id}/financial-profile.json` |
| 密码 | PBKDF2-SHA256（Web Crypto），不明文存储 |
| 重启网站 | **纯客户端**：确认后 unregister SW + 清 Cache Storage + 硬刷新；**不**清 localStorage / cookie，≠登出、≠清访客草稿、≠调后端 |

## 顶栏（移动精简）

- 保留：Logo、**剩余%**、用户名 / **访客** chip；访客另露「注册保存」
- 次要收进「更多」：已保存说明、快照、安装到桌面、**重启网站**、登录（窄屏）、登出

## 核心用户故事（摘要）

1. 打开即进主应用（访客示例数据 + demo 徽章）；改参只落本机。
2. 「注册保存」→ 当前草稿认领到新账号并同步云端。
3. 登录已有数据账号 → 用云端；空账号可确认绑定访客草稿。
4. 改税前工资 → 剩余 % 即时变；登录态自动同步云端。
5. 「更多 → 重启网站」→ 确认后清客户端缓存并刷新（部署后旧壳不生效时用）。
6. 登出 → 回到访客（本机草稿仍可继续改，不写云端）。
