# money-manage 移动端 UX / 产品 P0（落地包）

> PM / UX / 移动排版 / 图表子 agent 未交付完整结论时，按协调默认 P0 执行。  
> 交互分轨见 `lib/ux-contract.ts`（PC=popover；移动=sheet；断点 ≤639px）。

## 目标 / 非目标

- **目标**：手机上能快速改参、看剩余%、管支出、跳到走势图并看懂三张图；支持**多用户账号**（注册 / 登录 / 登出），登录后只读写**本人**财务数据。
- **非目标**：完整 CFP、复杂多账户权限、Auth SaaS、邮箱验证、找回密码、团队共享。

## 账号与数据边界（已改向）

> 旧表述「单用户自托管、无鉴权」已废弃。

| 项 | 约定 |
| --- | --- |
| 注册 | 用户名（3–32，字母数字下划线，唯一）+ 邮箱（唯一）+ 密码（8–72） |
| 登录 | 用户名或邮箱 + 密码；HttpOnly cookie 会话（约 30 天） |
| 试玩 | **未登录可本地试玩**（仅 `localStorage`）；**服务端 `/api/profile` 等须登录** |
| 绑定 | 登录 / 注册后若账号云端为空，自动把当前本地试玩数据绑定到该账号 |
| 隔离 | KV/本地键：`user:{id}` · `session:{token}` · `user:{id}/financial-profile.json` |
| 密码 | PBKDF2-SHA256（Web Crypto），不明文存储 |

## 建议降级（不删计算）

- 快照 / 安装到桌面：入口保留，不进首屏主路径强推。
- 消费影响分析：移动可用，不扩新模式。

## 核心用户故事（摘要）

1. 打开即看到「剩余 %」（可先本地试玩）。
2. 注册 / 登录后顶栏显示用户名，数据按账号隔离。
3. 改税前工资 → 可支配收入即时变；登录态下自动同步本人云端。
4. 加/改分期 → 月供与剩余 % 变化。
5. 跳「走势」→ 看清 30 年资产与现金流比率。
6. 登出后刷新：无会话则 `/api/profile` 401，页面回退本地试玩草稿。
