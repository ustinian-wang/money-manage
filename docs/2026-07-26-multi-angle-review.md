# money-manage 多视角评估与优化记录

日期：2026-07-26  
视角：PM、UX/UI、QA、开发

## 产品定位

`money-manage` 更适合定位为面向中国工薪用户的个人财务规划与消费承受力测算器，而不是日常流水记账工具。核心任务是回答：

1. 当前每月还能剩多少；
2. 一笔消费或分期是否承受得起；
3. 当前现金、理财和再投入策略会怎样影响长期资产。

已有优势是访客直达、轻示例、收入/资产/支出即时联动、消费影响分析和三类长期走势。当前瓶颈不是继续增加功能，而是结果口径、保存状态和首次决策路径是否可信。

## 本轮实现

1. 应急资金的默认现金与应急月数现金分存，切换只更换生效侧，并保持 `现金 + 理财 = 总资产`。
2. 资产预测只在理财余额中计算一次收益；负结余会消耗现金；一次性支出只在首月扣除。
3. 主图和消费分析的年度资产节点复用同一月度预测内核。
4. 快速连续编辑通过串行队列使用服务端确认后的 revision；409 保留本机草稿、锁住普通同步，只有措辞明确的操作才能用本机版本覆盖云端。
5. 增加 `typecheck` 和 `check` 脚本，将类型、单测和生产构建放进同一门禁。
6. 首屏决策摘要、409 sticky 告警、分区 chips+spy、本月支出同源聚合、GitHub Actions CI。
