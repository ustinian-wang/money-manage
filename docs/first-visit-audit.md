## P1（易困惑）

| 跟进 | ID | 现象 | 为何是问题 | 建议 | 状态 |
| --- | --- | --- | --- | --- | --- |
| - [x] | **P1-1** | 吸顶顶栏只见「剩余 · 23.8%」，无「剩余可支配收入占比」或一句话释义 | 首屏最醒目数字不知是预算剩多少、储蓄率还是别的；与示例高压叠加更焦虑 | 改为「剩余可支配 23.8%」或旁注 tip；点击展开一句公式 | **已处理**：文案「剩余可支配」+ `title` 公式 |
| - [x] | **P1-2** | 示例过重：税后约 1.35 万、总资产 50 万、父母 3k、生活 4.2k、车贷约 3.1k/月；剩余仅约两成 | 易误认「系统已知道我的情况」，或被「剩 23.8% + 车贷」吓退 | 首访用更轻演示（如仅房租/餐饮、资产更小）；条幅加「点数字改成你的」 | **已处理**：房租+餐饮、资产 8 万（`lib/demoDefaults`）；条幅加提示 |
| - [x] | **P1-3** | 默认「只看到手」；字段「月可支配收入」+「简便模式」；数字来自隐藏税前推算 | 「到手」口语与「可支配收入」书面混用；用户不知该改还是信 | 首访一句：「填银行卡到账 / 实际可花金额」；播种数旁标「演示值」 | **已处理**：标签「实际可花金额」+ 演示值徽章（访客） |
| - [x] | **P1-4** | 点「走势」已滚到资产图，分区 chip 仍高亮「参数」（390 实测） | 导航反馈撒谎，以为没跳成功；rootMargin 过窄时各区 ratio=0 不更新 | 点击 chip 强制 `setActiveSection`；ratio 全 0 时按距视口中线最近分区兜底 | **已处理**：`pickActiveSection` + 点击即高亮；IO+scroll 双端 spy |
| - [x] | **P1-5** | 应急资金默认收起且默认「0 个月」；月度剩余/调整后可用资产也藏在折叠里 | PRD 里安全垫是核心；收起 + 0 月 = 找不到又看不懂 | 折叠标题旁摘要「0 月 · 点开看结余」；或首访展开一次 | **已处理**：收起时摘要「x 月 · 点开看结余」 |
| - [x] | **P1-6** | 资产配置列表仅露总资产 +「联动」徽章；现金/理财/占比进浮层 | 密度好，但首访不知总资产里多少是理财，也不知「联动」=恒等式 | 摘要副文案「点开改现金/理财」；联动 tip「现金+理财=总资产」 | **已处理**：副文案 + InfoTip 公式 |
| - [x] | **P1-7** | 闲钱投资默认百分比 30%，无场景句 | 易与顶栏「剩余%」或资产配置比例混淆 | 标签改为「结余再投入」；旁注「每月结余的 30% 进理财」 | **已处理**：标签+旁注短句 |
| - [x] | **P1-8** | 滚到走势后再点参数区，点击被吸顶 header / 剩余胶囊拦截（Browser 实测） | 手机上改参像坏了 | `scrollIntoView` 预留 sticky 高度；或滚动后缩短/收起条幅 | **已处理**：`stickyAwareScrollY` 按 sticky 容器高度偏移 |
